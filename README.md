# Santosh Achari Catering Website

## Overview
A premium, fully‑responsive web presence for **Santosh Achari Catering**, showcasing an elegant brand identity, multilingual support (English, Hindi, Marathi), and a seamless inquiry experience.

### Key Features
- **Impressive SAC Monogram Logo** – animated gold‑gradient emblem with bold, readable typography.
- **Full Internationalisation** – language toggle (EN | हिन्दी | मराठी) using i18next; all UI text, form fields, and placeholders translate instantly.
- **Shubh Muhurat Calendar Widget** – interactive auspicious‑date selector for 2026‑2027 that pre‑fills the event date field.
- **Contact Form** – localized labels, validation, email routing to `bhushandhengle57@gmail.com`, and WhatsApp one‑click submission.
- **Signature Dishes Gallery** – price‑less dish cards with high‑quality food photography.
- **Testimonials** – authentic Indian portraits and dynamic Marathi testimonials.
- **Stat Highlights** – 5000+ Weddings, 1000+ Corporate Events, 1000+ Five‑Star Reviews, 35+ Years of Trust.
- **Modern Design** – glass‑morphism sections, subtle micro‑animations, vibrant gradients, and a dark‑mode friendly palette.

## Getting Started
```bash
# Install dependencies
npm install

# Run development server
npm run dev -- --open
```
Open http://localhost:5173 to view the site.

## Deploy
The project is built with Vite. For production:
```bash
npm run build
```
Deploy the `dist` folder to any static‑host (Netlify, Vercel, GitHub Pages, etc.).
